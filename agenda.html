S'abonner dans mon agenda

Rien ne s'est ouvert ? Le navigateur de cette application bloque sans doute l'ajout d'agenda : ouvrez la page dans le navigateur (étape 1), ou suivez « Ajouter à la main » ci-dessous.

Ajouter à la main

iPhone : Calendrier → Calendriers → Ajouter un calendrier → Ajouter un abonnement, puis coller l'adresse.

Android : sur calendar.google.com (dans un navigateur, version ordinateur) → Autres agendas → + → À partir de l'URL, puis coller l'adresse. L'agenda apparaît ensuite dans l'application.
